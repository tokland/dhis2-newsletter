DHIS2 Weekly Digest — 2026-09-17 to 2026-09-24

This week's biggest theme is DHIS2's evolving support for Apache Doris as an analytics database, with community discussions and several JIRA fixes addressing SQL incompatibilities and performance quirks. A severe metadata-creation bug tied to sharing settings, a tracker event table regression, and data-loss risks in indicator/option group deletion round out the technical highlights, while the community shared a strong nutrition logistics case study from Tajikistan and CDC's new LIS-DHIS2 integration toolkit gets a webinar.

DEVELOPMENT (JIRA)
------------------
- [EyeSeeTea] DHIS2-20068: Values missing in Form Field Plugins
  https://dhis2.atlassian.net/browse/DHIS2-20068
  Reported by an EyeSeeTea team member: values entered via Web Plugins can go missing in form fields. Currently In Progress - flagged for team visibility.
- DHIS2-22106: A single non-superuser sharing gap on a "default" Category/CategoryCombo silently breaks ALL metadata creates instance-wide, with zero diagnostic trace
  https://dhis2.atlassian.net/browse/DHIS2-22106
  A severe bug (now Closed/fixed) where a single missing sharing permission on default category metadata could silently block metadata creation across an entire instance with no error trace - important for admins troubleshooting mysterious create failures.
- DHIS2-21924: Restore missing `lastupdated` index on `trackerevent`/`singleevent` (regression from 2.43 event table split)
  https://dhis2.atlassian.net/browse/DHIS2-21924
  The 2.43 split of the event table dropped a critical `lastupdated` index, likely causing performance regressions for tracker/event queries; fix is In Progress.
- DHIS2-22098: Dataset validation with program-indicator-based rules can exhaust max_locks_per_transaction, failing with "out of shared memory"
  https://dhis2.atlassian.net/browse/DHIS2-22098
  Complex validation rules referencing program indicators can exhaust PostgreSQL's lock table, crashing dataset validation on large instances - a serious scalability concern currently Needs Info.
- DHIS2-21958: @Async has no configured default executor: SimpleAsyncTaskExecutor spawns an unbounded thread per call
  https://dhis2.atlassian.net/browse/DHIS2-21958
  Async operations lack a bounded executor, meaning every async call can spawn a new unmanaged thread - a resource-exhaustion risk on busy servers, currently Needs Info.
- DHIS2-9191: Updating a resource clears its sharing settings
  https://dhis2.atlassian.net/browse/DHIS2-9191
  A long-standing bug where updating a metadata resource wipes its sharing configuration is now in Testing, close to being resolved after years open.
- DHIS2-22028: OSM Light basemap tiles are watermarked - CARTO now requires an API key for its basemap service
  https://dhis2.atlassian.net/browse/DHIS2-22028
  CARTO's policy change now requires an API key for the OSM Light basemap, causing watermarked tiles in maps apps; fix has been completed (Done).
- DHIS2-22135: [Analytics][Doris] Indicators using SUBEXPRESSION fail: generated SQL uses PostgreSQL syntax (::numeric, double-quoted identifiers)
  https://dhis2.atlassian.net/browse/DHIS2-22135
  Indicators using SUBEXPRESSION break on Apache Doris because generated SQL still uses PostgreSQL-specific syntax - an active gap for anyone piloting Doris as an analytics backend.
- DHIS2-21793: Aggregate analytics subexpression queries generate PostgreSQL-specific SQL for Apache Doris
  https://dhis2.atlassian.net/browse/DHIS2-21793
  A related Doris SQL-compatibility fix for aggregate analytics subexpressions has now been Closed/delivered.
- DHIS2-22161: Indicator group delete also deletes the related new indicator
  https://dhis2.atlassian.net/browse/DHIS2-22161
  Deleting an indicator group unexpectedly deletes the indicators inside it too - a data-loss risk for admins doing metadata cleanup, currently To Do.
- DHIS2-22154: Deleting an OptionGroup permanently deletes its member Option(s), not just the group
  https://dhis2.atlassian.net/browse/DHIS2-22154
  Similarly, removing an OptionGroup cascades to permanently delete its member Options rather than just the grouping - another metadata data-loss risk, To Do.
- DHIS2-22055: App Hub allows downloading incompatible app versions
  https://dhis2.atlassian.net/browse/DHIS2-22055
  The App Hub doesn't block downloads of apps incompatible with your DHIS2 version, risking broken installs; still To Do.
- DHIS2-21389: JDK 25 upgrade
  https://dhis2.atlassian.net/browse/DHIS2-21389
  The platform's JDK upgrade to version 25 has been completed (Closed), an infrastructure milestone relevant to developers managing DHIS2 server environments.
